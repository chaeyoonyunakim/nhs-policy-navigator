# NHS Policy Navigator -- documentation

The NHS Policy Navigator is an adaptive multi-source retrieval agent over the
**NHS 10 Year Health Plan "Fit for the Future" (July 2025)** plus live NHS
England sources. It reasons about *how* to retrieve and *which* sources to use
before retrieving, then logs every decision so it can adapt over time.
